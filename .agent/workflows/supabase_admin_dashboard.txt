===============================================================
                    WHAT WAS BUILT
===============================================================

A complete admin interface to manage your Supabase database and storage
directly from the Sangatamizh app, bypassing the need to log into
Supabase console for common tasks.

1. SQL EDITOR 💻
   -------------
   - Write and execute raw SQL queries
   - View results in a formatted table
   - Check errors instantly
   - Perfect for custom data fixes or quick checks

2. TABLE EXPLORER 📊
   -----------------
   - Browse all tables in your database
   - View table data (auto-paginated)
   - Inspect JSON columns properly
   - Refresh data with one click

3. STORAGE MANAGER 🗄️
   ------------------
   - List all storage buckets
   - Browse files within buckets
   - Upload new files (Audio, Images, etc.)
   - Delete files directly
   - View file metadata (Size, Name)

===============================================================
                HOW TO USE
===============================================================

1. Access the Dashboard
-----------------------
- Login as admin (email contains "admin")
- Look for the green floating button (Database icon)
- Bottom-right corner (above player if active)

2. SQL Tab
----------
- Type SQL query: `SELECT * FROM songs LIMIT 5;`
- Click "Run"
- See results in the table below

3. Tables Tab
-------------
- Select a table from the sidebar (e.g., `songs`)
- View the data instantly
- Use it to verify uploads or check data health

4. Storage Tab
--------------
- Select a bucket (e.g., `songs`, `covers`)
- See all files in that bucket
- Upload new files using the "Upload" button
- Delete files using the trash icon
