    4. HEART BUTTON STATES
    =======================

    State 1: NOT LIKED
    ------------------
    Color: #FFFFFF (White)
    Fill: none (Outline only)
    Icon: 🤍
    Data: !likedIds.includes(songId)

    State 2: LIKED
    --------------
    Color: #FF4B4B (Red)
    Fill: currentColor (Filled)
    Icon: ❤️
    Data: likedIds.includes(songId)


    5. BACKEND STRUCTURE

      ↓

      ↓
    likesService.toggleLike(userId, songId)
      ↓
    Return: {ok: true, liked: boolean}

    Service (likes.service.js)
    ---------------------------
    toggleLike(userId, songId)
      ↓
    dbService.toggleLike(userId, songId)
      ↓
    Return: {liked: result.liked}

    6. ERROR HANDLING
    =================

    Error Type 1: Not Logged In
    ---------------------------
    Trigger: !user
    Action: Show login modal
    Message: "Please login to like songs! 🎵"

    Error Type 2: Server Error
    --------------------------
    Trigger: !res.ok
    Action: Throw error
    Message: "Server error: 500"
    Toast: "Failed to update like status 😞"

    Error Type 3: Network Error
    ---------------------------
    Trigger: fetch() fails
    Action: catch block
    Message: "Failed to update like status 😞"
